# Milspår documentation

Detta katalogträd är projektets beslutade baseline för produkt, design och arkitektur.

- `PRODUCT-SPEC.md` — funktionell produktdefinition och scope
- `ROADMAP.md` — MVP och efterföljande steg
- `ARCHITECTURE.md` — tekniska principer och Docker-arkitektur
- `DATA-MODEL.md` — domänmodell och relationer
- `design/DESIGN-SYSTEM.md` — låst grafisk baseline v1.0
- `design/UI-SPEC.md` — navigations- och responsivitetsregler

## Ändringsprincip

Design System v1.0 är **LOCKED**. Nya vyer ska följa systemet. Ändringar av färger, typografi, spacing, navigation eller grundläggande komponentstil ska göras som ett uttryckligt versionsbeslut, inte som lokal förbättring under implementation.
