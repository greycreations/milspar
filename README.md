# Milspår

**Hela bilens historia.**

Milspår är en självhostad, responsiv webbapp för att samla och följa hela livscykeln för ett eller flera fordon: service, underhåll, verkstadsbesök, reparationer, däck, kostnader, dokument, bilder och mätarhistorik.

## Projektstatus

Milspår befinner sig i specifikations- och designfas. Första målet är en Docker Compose-baserad version för egen drift.

## Grundprinciper

- Flera fordon i samma installation
- Mobile-first registrering och desktop-first överblick
- Händelsebaserad historik med full spårbarhet
- Dokument och bilder är förstklassiga objekt
- Originalfiler bevaras
- Local/self-hosted first
- API-förberedd arkitektur
- Responsivt gränssnitt för dator, surfplatta och mobil
